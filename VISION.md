# Vision

Neuro Desktop exists to give Neuro and Evil a reliable Windows control surface
that can interoperate with dedicated game integrations and Neuro Relay.

## Product Direction

1. Safe Control
   - Provide high-level intents first, with low-level input behind clear safeguards.

2. Integration Hub
   - Bundle Neuro Relay and support multiple concurrent integration sessions.

3. Observable Automation
   - Every action should be traceable with structured logs and replayable context.

4. Extensible Platform
   - Support discoverable integrations/plugins through a signed catalog.

5. Production Reliability
   - Deterministic builds, automated tests, clear release process, and rollback paths.

## Non-Goals (Current)

1. Unrestricted autonomous system-level execution without permission gates.
2. Broad cross-platform parity before Windows pipeline is production-stable.
3. Marketplace monetization before trust and signing foundations are complete.
